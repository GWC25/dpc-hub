───────────────────────────────────────────────────────────────────────────────
WHAT EACH FILE DOES
───────────────────────────────────────────────────────────────────────────────

hub.html (Main App)
  • Single-page application shell
  • Sidebar navigation (Quick Capture, Dashboard, Evidence Log, HoA Tracker, etc.)
  • Quick Capture section with activity type selector
  • Dynamic form rendering container
  • Evidence log display
  • Settings page
  • Toast notification container
  • Loads webparts.js, templates.js, hub.js

index.html (Landing Page)
  • Digital Learning Pyramid visualization (3 colored boxes)
  • Learning Without Barriers banner
  • Statistics cards (34 areas, 30+ templates, 45+ components, ∞ entries)
  • Role description
  • Call-to-action buttons (Open Hub, Documentation)
  • Fully responsive design

hub.css (Styling)
  • CSS variables for colors, spacing, typography
  • Header styling (gradient background, layout)
  • Sidebar navigation (vertical list, active states)
  • Main content area (flexible layout)
  • Form styling (inputs, buttons, sliders, tables)
  • Accessibility (focus states, high contrast, WCAG 2.2 AA)
  • Responsive breakpoints (desktop, tablet, mobile)
  • Print styles
  • Animations (fade-in, pulse)

webparts.js (Form Components)
  • Exports WebParts object with 45+ component functions
  • Each function returns object with:
    - container (HTML element to append to DOM)
    - getValue() (extract form value)
    - setValue() (set form value programmatically)
    - clear() (reset to blank)
  • Components:
    - Text inputs (text, date, email, url)
    - Text areas (multi-line with optional mic)
    - Dropdowns (linked to config data)
    - Checkboxes (people picker, previous actions)
    - Sliders (mood/stress/confidence)
    - Tables (attendees, action points)
    - Complex (tags, thread linker, evidence links)
  • Helper functions (addActionRow, addAttendeeRow, etc.)

templates.js (Template Assembler)
  • TemplateAssembler object with buildForm() function
  • Takes template definition from config + config object
  • Loops through template.webParts array
  • For each webpart ID, calls renderWebPart()
  • renderWebPart() routes to correct WebParts function
  • Builds form in 2-column layout (left/right split)
  • Adds save buttons at bottom
  • buildEntryFromForm() collects form values into entry object

hub.js (Application Logic)
  • Global variables: CONFIG, ENTRIES
  • navigateTo(sectionId) — Switch between sections
  • loadConfig() — Fetch data/config.json, initialize app
  • loadAreas() — Display curriculum areas in settings
  • loadTemplate(templateId) — Render form for selected template
  • saveEntry(templateId) — Collect form data, save to localStorage
  • logEntryToEvidence() — Add entry to Evidence Log view
  • clearForm() — Reset form fields
  • exportToJSON() — Download entries as JSON file
  • showToast() — Display notifications
  • DOMContentLoaded listener — Initialize on page load

config.json (Master Configuration)
  • metadata: role, institution, status, version
  • phases: Phase 1/2/3 definitions
  • commonPurposes: 10+ tags (Accessibility, AI, Jisc, TLA, Teams, Digital Leads, LSB, QA, Ofsted)
  • templates: 30+ template definitions
    - id, name, category (Meeting, Teach.Meet, Coaching, CPD, COGs)
    - webParts array (which form components to include)
    - defaultTags array (auto-populate for this template)
    - description
  • webParts: Reference definition of all 45+ form components
  • cogsThemes: List of COGs programme themes
  • peopleRegistry: Graeme, Neil, Ben, plus space for staff

areas.json (Curriculum Areas Reference)
  • Array of 34 areas
  • Each area has:
    - code (3-letter code: AGF, AHE, ANM, ..., SPO)
    - name (full name)
    - hoa (Head of Area name - editable)
    - digitalLead (Digital Lead name - editable)

HOW TO PUSH TO GITHUB (5 STEPS)
───────────────────────────────────────────────────────────────────────────────

1. Create Repository
   • Go to https://github.com/new
   • Name: dpc-evidence-hub
   • Description: Digital Pedagogy Coach Evidence System
   • Public or Private: Your choice

2. Clone Repository
   git clone https://github.com/[your-username]/dpc-evidence-hub.git
   cd dpc-evidence-hub

3. Copy Files
   • Copy all files from the dpc-evidence-hub folder you downloaded
   • Into the cloned repository folder

4. Push to GitHub
   git add .
   git commit -m "Initial DPC Evidence Hub v3.0"
   git push origin main

5. Enable GitHub Pages
   • Settings > Pages
   • Source: main branch, / root
   • Wait 1-2 minutes

Then your hub is live at:
  https://[username].github.io/dpc-evidence-hub/hub.html
