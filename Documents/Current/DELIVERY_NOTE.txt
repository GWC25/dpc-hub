HOW TO GET STARTED (5 MINUTES)
───────────────────────────────────────────────────────────────────────────────

1. DOWNLOAD THE FOLDER
   • Extract dpc-evidence-hub/ folder to your computer

2. OPEN THE APP
   Option A (Easiest):
   • Open hub.html directly in your browser (Chrome/Edge recommended)
   
   Option B (Better):
   • Run local server: python3 -m http.server 8000
   • Visit: http://localhost:8000/hub.html

3. LOAD CONFIGURATION
   • Click "Load Config" button in header
   • Should see: "Configuration loaded successfully" + 34 areas + 30+ templates

4. TRY QUICK CAPTURE
   • Click "Quick Capture" in sidebar
   • Select a template (e.g., "Line Manager 1:1")
   • Fill out test entry
   • Click "Save entry"
   • See it logged in Evidence Log

5. EXPORT
   • Click "Export" button
   • JSON file downloads
   • You now have evidence ready for OneDrive

DATA ARCHITECTURE (IMPORTANT)
───────────────────────────────────────────────────────────────────────────────

Browser Storage (Temporary):
   • Entries saved to browser localStorage during the day
   • If you clear cache, entries are lost
   • NO automatic backup

OneDrive Storage (Persistent):
   • Click "Export" to download JSON file
   • Upload to OneDrive/Digital-Coach-Evidence/[appropriate folder]
   • Structure is domain-split:
     - hoa-meetings/ (one file per area)
     - learning-walks/ (one file per area)
     - training-delivered/ (by topic)
     - digital-leads/ (coaching logs)
     - cpd/ (professional development)
     - metadata/ (reference files)
     - reporting/ (for AI synthesis)

Recommendation: Export at END OF EACH WEEK, upload to OneDrive

───────────────────────────────────────────────────────────────────────────────
TROUBLESHOOTING
───────────────────────────────────────────────────────────────────────────────

Problem: Config won't load
   → Check data/config.json exists
   → Hard refresh (Ctrl+Shift+R)
   → Check browser console (F12) for errors
   → Validate JSON at https://www.jsonlint.com

Problem: Form won't render
   → Open DevTools (F12)
   → Check Console tab for JavaScript errors
   → Verify template ID matches exactly (case-sensitive)

Problem: Can't find saved entries
   → Entries are in browser localStorage (until you export)
   → If you cleared cache, entries are gone
   → Check exported JSON files on your computer

Problem: Export button not working
   → Make sure you've created at least one entry
   → Check browser console for errors
   → Try hard refresh

See docs/SETUP.md for more troubleshooting tips
